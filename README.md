# OmniTools Hub — 50 Utility Micro-Apps & AI Suite

OmniTools is a suite of 50 high-utility web applications covering B2B finance, e-commerce margin auditing, developer tools, marketing generators, and personal finance calculators.

## Features
- **50 Micro-Apps:** Calculators, converters, formatters, and generators.
- **AI-Powered Utilities:** Built-in serverless integration for text polishing, legal drafting, and regex generation.
- **AdSense Ready:** High-eCPM responsive ad placements built directly into the UI layout.
- **SEO Optimized:** Dynamic OpenGraph, metadata, and JSON-LD schema injection for search engines.

## Tech Stack
- Frontend: Single-page application (HTML5, Vanilla JavaScript, CSS3)
- API: Vercel Serverless Function (Node.js)
- Hosting: Vercel

## Deployment
1. Import this repository into Vercel.
2. Add your `OPENAI_API_KEY` to Vercel Environment Variables.
3. Deploy!
